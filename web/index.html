Catatan Penting:

  • Button menggunakan INPUT_PULLUP internal → tidak perlu resistor pull-up eksternal. Cukup hubungkan kaki satunya ke GND.
  • LCD I2C secara default beralamat 0x27. Jika LCD tidak menyala, coba alamat 0x3F dengan mengganti lcd(0x27,16,2) menjadi lcd(0x3F,16,2).
  • Gunakan adaptor 5V 2A minimum untuk memberi daya ke semua modul secara stabil.
  • Jangan sambungkan relay 5V ke pin 3.3V — dapat merusak komponen.
